## 🌟 About The Project

**AlHayat AI Restaurant** is a modern AI-powered restaurant management and online food ordering platform designed to make dining smarter, faster, and more convenient.

The platform combines an interactive food menu, online ordering experience, AI-powered food recommendations, table reservations, order tracking, and career applications in one place.

It aims to deliver a smooth digital restaurant experience for both customers and restaurant administrators.

## ⚙️ Run Project Locally

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

```bash
cd Alhayat-AI-Restaurant
```

### 3. Start the Backend

```bash
cd Backend
npm install
node server.js
```

Backend runs on:

```text
http://localhost:8000
```

### 4. Start the Frontend

Open the `Forntend` folder in VS Code.

Right-click on `index.html` and select **Open with Live Server**.

Frontend runs at:

```text
http://localhost:5500
```

### 5. Environment Configuration

Create a `.env` file inside the Backend folder and configure your required environment variables.

Example:

```env
PORT=8000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

Use your own credentials. Never upload your `.env` file or secret keys to GitHub.
